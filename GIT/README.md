## Booking setup
This site is static. For live scheduling, replace the placeholder booking link with your real Cal.com or Calendly URL.

Example:
- Replace `https://cal.com/your-handle/30-min-consult` with your real booking page.
- If using an embed, paste the Cal.com embed snippet into the booking section.
